# Alpha战斗重置回归边界

重置以25职业、546卡、97怪物、8 Boss的正式目录及新物理引擎为准。
原战斗测试中旧职业规则已由以下行为测试替换，保留数据库事务、工坊、药剂、同行、区域、奖励与装备兼容用例。

- battle-rework-runtime：545张可出牌和空白禁用；25职业跨等级逐阶段JSON恢复；8 Boss恢复。
- battle-rework-physics：基础加倍率、分段与逐目标双爆、乘区封顶、速度、效果命中、DOT快照和层数、强控免疫、盾、群怪血池。
- battle-rework-monsters / monster-action-behavior：真实状态条件、支援预算、锁定意图及实际执行。
- battle-rework-bosses：考试、收证、怨念、潮相、梦境、镜面、炉温、部件反制与恢复。
- astrology-battle / magician-battle：玩家选牌、资源支付一次、临时卡星级、空白限制。
- battle-rework-attributes / progression-integration：10点预算、加退点、迁移、升星及结算。

已废止的旧契约（对应规则不再要求保持旧值）：
- 按旧版让速度、敏捷、坚韧和百分比减伤参与实际结算
- 按攻击前护盾结算双向防反，并让天赋与buff分别叠加反击次数
- 多段攻击每段都按该段攻击前的当前护盾重新计算防反
- 双方同时拥有防反时只结算原攻击目标的一次防反
- 新防反造成的伤害不会触发旧荆棘的二次反弹
- 工坊before_damage机制不能改写防反的固定公式伤害
- 防反公式锁定零防御、150%上限与四舍五入边界
- 按旧版实际结算冻结、再生、流血与濒死保护
- 按旧版概率为普通怪物生成迅捷词缀和敏捷效果
- 按旧版把牧师对自己的过量治疗等量转化为当前目标伤害
- 让攻击力同时进入攻击牌与中毒、灼烧、流血、腐蚀乘区
- 怪物净化者优先行动并解除队友冻结，使队友能够继续行动
- 让烧血绕过护盾且保留 1HP，并限制主动弃牌每回合一次
- 在普通牌无法支付完整烧血时原子拒绝，并允许恰好保留 1HP 的边界
- 让治疗自己的卡牌先恢复生命再结算烧血
- 低血时不允许借治疗凯利安绕过玩家自身的烧血门槛
- 把三张“中毒层数翻倍”牌按乘法结算而不是中毒 +2
- 按职业限定资源并让龙魂、炉温、风痕、雷荷与零件进入实际伤害
- 元素法师打出无元素功能牌后仍保留上一个元素
- 雷系消耗牌结算后仍按魔力消耗回充1层
- 风暴核心的充能技能写入雷荷职业资源
- 结算武器大师同名连击，并在新回合清空计数
- 按理智分档强化暗黑牧师伤害，并在零理智时按 50% 攻击自己
- 锁定并在回合开始结算奥术吟诵，同时回复 1 魔力
- 吟诵队列已满时不消耗行动点、魔力或手牌
- 按受伤批次显示、强化、消耗并过期深渊回声
- 迁移旧进行中战斗的深渊回声而不丢失层数
- 非深渊法师受伤时清理旧存档残留的深渊回声
- 只限制 30% 面板加点，装备与藏品可继续叠加并让凯利安、特莱奥继承总吸血的 80%
- 下一张法术、召唤与机械召唤减费只在匹配卡牌打出时生效并消耗
- 法术与雷系增幅按卡牌类型计算并只由有效伤害法术消耗
- 治疗与护盾法术正确叠加通用法术、治疗护盾专用增幅
- 回合结束伤害在玩家结束回合时按文本数值结算
- 灵魂收割只在实际击杀时回复 6 点魔力
- 对不死敌人的持续加成按全体卡的每个目标分别计算
- 双重契约让新召唤物立即额外行动，召唤增幅提高后续技能数值
- 再次召唤同名限时召唤物会刷新完整存在回合而不是直接跳过
- 可攻击召唤物拦截敌方攻击，机械召唤物行动后按存在时间离场
- 同名状态按施加实例保留各自数值与持续时间
- 中毒翻倍会逐层翻倍并保留每层原本的持续时间
- 旧存档的聚合状态会作为单个兼容层继续倒计时
- 按指定减益判定绞杀根，并让爆燃按全部灼烧数值乘算
- 公式破坏按敌方独立强化层数造成伤害
- 按旧版公式让每个减益伤害计入攻击力与深渊回声
- 自身失血绕过护盾、敏捷与防御直接扣除生命
- 召回按剩余回合与生命比例回魔，最终协议只摧毁机械并攻击全体
- 法术回收、召唤回收与最早吟诵都按卡牌文本筛选
- 法师职业的技能牌不会误消耗下一张法术减费
- 移形换位获得风痕，自动锻锤只在技能实际触发时获得炉温
- 商人买路钱按敌人数量、等级与难度计价，逃跑随机损失金币
