# 创意工坊组合规则

在职业卡牌的积木台点击 **组合规则**，或在天赋中添加 **组合规则天赋**。旧的基础积木和已保存作品继续使用原格式；编辑与导入仍先进入草稿，保存后才更新作品。无需编写 JavaScript。

## 组合方式

每组规则由触发事件、条件、优先级、冷却、支付代价和顺序执行的积木组成。可以放在卡牌、天赋、状态或召唤物身上。

- 事件包括使用卡牌、回合开始/结束、伤害/治疗/护盾结算前后、暴击、闪避、死亡、状态变化、抽牌、弃牌、召唤与资源变化。
- 数据可以属于本次执行、卡牌实例、状态实例、单位、回合或战斗。不同作品的数据隔离；需要跨卡牌共享的资源使用“改变资源”和“读取单位资源”。
- 公式支持属性、事件结果、数据引用、状态数据、目标筛选、四则运算、比较及且/或条件。“读取状态数据”填写 `引用编号.数据名称`，也可使用状态显示名称；同类独立状态的数值相加。
- 每个效果可把结果保存为名称，后续使用“读取记录 / 本次执行”引用，例如 `result.hpDamage`、`result.overflow`。多目标和多段伤害结果是该效果的合计数。
- 可嵌套如果/否则、逐目标执行、重复和延迟。延迟默认在实际触发时计算数值，可勾选锁定安排时的数值，目标失效时可取消、重选或执行替代步骤。
- 支付代价先核对所有项目，全部满足后才扣除。使用卡牌时支付失败会回滚整次出牌；被动事件没有足够资源时跳过该规则。
- 单次连锁有执行数量和递归保护，用于终止自触发死循环。没有按“强度评分”禁止保存作品。

## 自定义状态与现有效果

每个状态独立配置显示名称、Buff/Debuff 类别、基础命中、持续回合、叠加方式、净化/驱散权限、自身数据、复用效果和事件规则。`-1` 回合表示持续生效直到规则移除或战斗结束。

现有效果库来自职业、怪物技能和基础积木，保留规范状态类别、数值单位、次数和原有触发内容。可复用冻结、嘲讽、迅捷、弱化、易伤、DOT、反击等；纯标记仍作为条件和联动的数据，没有额外的伤害乘区。名称与效果分开，自定义“石化”可选择冻结；同一状态可有多个原生效果和多条事件规则。

敌对目标上的自定义状态会计算基础命中、施加者效果命中与目标效果抵抗，不因把显示类别设为 Buff 而绕过检定。冻结式效果继续使用现有控制免疫及 Boss 控制转化。玩家和召唤物的嘲讽接入同一套单体选目标规则。

父状态移除时只删除它提供的效果；其他来源保持独立。一次性控制或保护被消耗后，不会因为父状态还在就自动重建。

## 示例

| 示例 | 可继续修改的组成 |
| --- | --- |
| 生命之契 | 独立 remaining 额度；不可净化；存在期间易伤；治疗优先抵扣；超出额度的剩余量才恢复生命 |
| 蓄伤护符 | 记录实际扣除生命的30%，下次行动开始生成护盾并清空记录 |
| 治疗转护盾 | 读取真正的溢出治疗量并生成护盾 |
| 死亡传递印记 | 死亡事件筛选存活友方，传递当前额度 |
| 守护姿态 | 防御提升与结算前减伤组合 |
| 石化 | 名为石化的状态复用冻结控制 |
| 守护傀儡 | 主人低血量时优先嘲讽加减伤，否则攻击；保护行为有冷却 |

生命之契示例使用严格大于判断：额度200，治疗200时额度归零但状态仍存在；下次正数治疗会解除。可把条件改为大于等于。没有被抵扣的治疗才会计入溢出；满血目标也能通过治疗抵扣额度。

## 卡牌、召唤与数值

输出积木默认采用1/1.1/1.2的三星系数，可为每个伤害、治疗或护盾积木分别设置。普通伤害遵守现有命中、双暴、防御和其他乘区；群体效果逐目标、逐段独立判定暴击。DOT使用施加时攻击力快照，不吃双暴。

“使用已结算金额”可避免储存伤害再释放时重复应用防御、双暴和直接增减伤；仍会受生命、护盾等实际可承受额度限制。AP、额外抽牌、护盾、DOT和控制沿用现有战斗规则。

卡牌操作支持生成指定卡、复制、移动、变形、移出循环、修改实例费用。复制得到独立实例；变形采用新卡的费用。召唤物支持属性继承、登场/离场事件、条件和冷却；行动开始时仅执行优先级最高且满足条件的一条行动规则。

组合模板保存在本机。职业包导出包含规则、状态与召唤定义，随作品一起导入。战斗存档保存状态额度、每场/每回合触发记录、冷却、延迟动作和卡牌变更；恢复存档不会重放已经执行的动作。

在创意工坊测试场的战况中展开“积木执行记录”，查看条件未成立、代价不足、输出结果和触发事件。正常战斗卡面保持技能效果和数值展示。
