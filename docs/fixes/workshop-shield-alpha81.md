# Alpha 81：护盾伤害配置与卡面

## 原因与边界

旧效果编辑器的 `hasValue` 判断漏掉了 `supported &&`，导致按护盾伤害、移除护盾等效果也显示固定值和属性公式。玩家可以填入并导出这些字段，但它们不参与该效果的结算。

`damage_from_shield` 实际按玩家当前护盾乘 `ratio` 结算。战斗卡面此前却落入通用说明分支，复用整张卡的手写描述并附加无效 `value/scaling` 算出的数值，进一步造成误导。

修复编辑器字段与比例说明、按真实护盾值生成卡面、在战斗记录中标出护盾伤害来源。没有更改伤害计算、暴击规则、导入规范或玩家作品。

上传样本的两个直接伤害技能均配置了普通伤害与护盾伤害；其召唤物唯一伤害技能也有这两个效果。各效果分别判定暴击可以产生一段普通、一段暴击。该样本能够解释“此卡组的所有伤害技能都是两段”；不能据此断言其他职业或未提供的玩家存档没有额外问题。

## 验证

- `npm run check`、`npm run content:verify`、Alpha 81 构建通过。
- 完整测试：104 个文件，1377 项通过。新增交互回归覆盖无效字段隐藏、比例编辑、旧数据保留、单个混合公式编辑；真实仓库回归覆盖单次暴击、两个积木分别暴击及未暴击预览。
- 使用 [独立酒馆环境](../testing/tavern-alpha80.md) 的 SillyTavern 1.18.0 + 助手 4.9.5，加载 Alpha 81 候选。原始上传内容仅复制到独立测试环境，未提交仓库或发布。
- 合成状态固定玩家生命 1000、护盾 400，敌方防御设为伤害倍率 25%。两个原始直接伤害技能分别重现普通伤害后接护盾暴击；实际界面选牌显示两个基础值，点击出牌只有一次使用记录和一次费用消耗，护盾伤害记录包含来源。
- 单效果对照覆盖普通伤害、暴击、有无敌方护盾：每次只有一个伤害事件；显式设置两次攻击时才有两个事件。暴击预览始终使用未暴击基准。

## 可选上传样本复验

仅在隔离酒馆的 `public/caelian-qa/uploaded-pack.json` 放置待复验职业包，重建并复制 `.tavern-qa/` 全部文件。打开测试聊天后点击“上传卡组护盾伤害”。此探针为本次含 50% 护盾效果的样本设计，通过真实公共 API 出牌、真实数据库读取命中事件，并留下可手动选牌的战斗。

“结束测试并查看工坊”仅归档该测试存档的战斗，用于核对编辑界面。工具不修改样本文件，不上传反馈，也不打包进入正式 Alpha 产物。不要将工具加载到玩家的常用酒馆。
