| 卡面、血条预览和实际伤害难以对应 | 卡面注明基础值；自定义卡血条预览采用新版防御结算并扣除护盾；内置同名卡按选中的实体星级预览；日志注明技能来源、暴击、护盾与生命变化；编辑器显示攻击次数。 |

## 伤害复现

通过真实 `battle.play-card` 仓储命令测试：攻击 300，技能 `100 + 100%攻击`，敌人防御设为攻击方 `K=100+5×等级` 的三倍。旧血条预览为 319，实际非暴击伤害为 100，暴击伤害为 150；修复后非暴击血条预览为 100。增加 60 护盾后预览为 40，实际生命分别损失 40/90，日志显示护盾吸收 60。

单个 `damage` 且攻击次数为 1 时，只产生一次伤害事件。固定值和百分比先合并，再计算防御与暴击。明确配置 `hits: 2` 才重复攻击，日志标记第 1/2、2/2 次。玩家所述“未设置多段却出现普通伤害和暴击两次数值”尚无对应技能导出或战斗日志，不能声称已复现其具体原因。

- 完整自动化：102 个文件、1,365 项通过；类型检查、lint、46 个内容文件校验及 Alpha 构建通过。
- 酒馆实机：2026-09-12 在独立 SillyTavern 1.18.0 + 酒馆助手 4.9.5 完成，使用测试角色、世界书副本及合成存档；见下表。使用正式候选产物，HTTP 下运行，未连接真实模型 API 或 MVU。
- 发布通过 PR #2 的检查后合并 main，由既有 Alpha 工作流发布；Beta 发布工作流未请求执行。

副 API 测试使用明确标注的固定响应，只验证调用、节点和持久化逻辑；没有把合成正文称为真实模型输出。迟到请求、旧楼层后处理/删除、旧版手动检查点迁移及后续自动进度回退另由仓储和内核集成测试覆盖。特定模型为什么持续判 stay，以及玩家那张单段卡为何显示两个数值，需要其输入输出或卡牌日志才能进一步归因。
