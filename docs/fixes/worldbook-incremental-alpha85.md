# Alpha 85：世界书增量更新与删除冲突

## 问题和修复

皇权世界书更新曾按浏览器中的整批成功回执跳过后续读取。玩家重新导入旧世界书后，条目实际缺失，但自动检查和手动更新都可能返回“最新”。

现在每次从当前角色实际绑定的世界书读取条目，逐项执行作者差量。历史回执只作记录，不再用于跳过检查。多批次新增及其后续修订合并后，缺失条目直接插入最终版本。

## 更新规则

- 新增条目仅插入，不整本替换；保留玩家自建条目。
- 新增条目已经存在时保留其本地内容。新插入条目携带独立身份标记，后续改名或改写不会重复插入。
- 既有条目的作者修订按旧版、作者新版、本地版本三方核对；玩家修改的正文及设置保留，未改字段可更新。
- 作者删除的条目若仍等同原版，自动删除。
- 删除涉及本地正文或设置改动时，弹窗显示具体条目、差异字段及正文预览，提供“保留我的条目”和“按新版删除”。其他安全增量先完成。
- 保留选择按角色、世界书及条目快照记录。设置中的“重新选择保留的旧条目”可以重做选择。删除批准不保留给未来重新导入的条目。
- 确认后重新读书并比较确认时的完整快照；弹窗期间再次改动的条目不会被删除。
- 写回前保存备份，写回后核对全部条目的正文、设置和身份。接口漏写、未保存等错误明确报告，不写成功回执。

## 玩家操作

更新 Alpha 85 后，打开设置并点击更新世界书／角色卡。缺失的新条目会补入。有删除冲突时逐条选择；选择保留不阻止其他新增内容写入。

设置结果区分别显示“未更新条目”和“已保留的本地内容”。后者是尊重本地修改的结果，不是更新失败。成功无变动时显示“已核对实际内容，没有待写入的更新”，避免把保留的自定义内容误称为完全等同作者最新版。

## 回归验证

覆盖已有成功回执后重导旧世界书、单项缺失自动补入、多个作者版本合并、玩家修改与重命名保留、同名自建条目保护、删除保留与再次选择、删除批准不跨重导复用、弹窗期间再次编辑、写回失败重试及设置字段回读失败。另执行全量测试、类型检查、lint、内容数据核对和 Alpha 构建。
