# 四敌遭遇 Invalid damage 修复

## 已确认的根因

Alpha 88 / Beta 1.26 把普通遭遇人数上限扩展到四个，`model.mjs` 的伤害缩放表仍只有 1、2、3 人条目。四敌生成时 `damageScale` 为 `undefined`，`offenseGroupFactor` 为 `NaN`，后续敌方直接伤害和 DOT 快照都会被污染。

组合规则包装器会取消无效基础伤害，因此吟游诗人可能先看到敌方直伤为零。敌方 DOT 在下一次玩家回合结束时进入 `rawHit`，最终报 `Invalid damage {"amount":null,...}`。JSON 中的 null 实际对应 NaN。本次截图报错来源是巨鼠；魔药史莱姆和其他 DOT 敌人也能触发，并非职业或史莱姆专属问题。

## 修复

- 三个及以上普通敌人沿用敌方规划器现有的 0.48 基础系数；1、2 人及 Boss 系数保持原样。
- 读取旧四敌存档时恢复损坏的缩放系数和伤害预告，保留原锁定技能、目标及随机状态。
- 对受到该缺陷影响的无效 DOT，按来源当前攻击、原倍率及正确遭遇系数重建伤害快照。旧快照已经丢失，无法反推出施加当时的攻击值；这次恢复会写入战斗记录。
- 已合法的 DOT（包括零伤害）保持原值；不刷新状态持续时间、层数或来源。来源死亡后已施加的 DOT 仍正常结算。
- 阻止旧投影里的 NaN/null 再把已恢复的快照覆盖成零；显式合法的零伤害修改仍生效。

## 验证

使用卡牌广场公开的吟游诗人配置，重放巨鼠、魔药史莱姆、发条蜘蛛、图书馆拟态书的四敌战斗：第一回合使用持续回血/护盾、行吟、放浪神光环、烈毒咬箭、狂风蚀箭，第二回合使用烈毒咬箭与军神光环。

修复前稳定在第二回合结束时出现截图同类的巨鼠 Invalid damage；修复后正常进入第三回合。另用同一配置模拟旧版损坏存档，恢复后同样进入第三回合，DOT 伤害保持有限且大于零。

仓库回归用例覆盖 1–4 敌直伤和 DOT、真实锁定敌方行动、NaN/null/Infinity 存档、旧投影同步、来源死亡、剩余时间、合法零伤害及重复读档的幂等性。
