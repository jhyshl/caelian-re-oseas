# 凯利安角色卡 / 世界书受控增量更新协议

Alpha 运行层只会在以下条件全部满足时处理远程内容清单：

- 当前角色卡名称精确为 `凯利安`；
- 当前角色卡的主绑定世界书是 `孔雀开屏你说看不见`；
- 为兼容已经导入的 v3 卡，也接受其旧绑定名 `孔雀开屏你说你看不见`；
- 清单目标仍处于上述白名单；
- 每条操作具有从未复用的唯一 `id`。

接入器不会整卡覆盖。管理端在 `public/managed-content/alpha.json` 中发布命令，
运行层按命令定位角色字段、酒馆助手脚本或指定世界书条目，并只修改精确片段。

## 文本操作

- `replace-exact`：旧片段必须恰好出现一次，否则停止该条更新。
- `delete-exact`：待删除片段必须恰好出现一次；已经不存在时视为完成。
- `insert-before` / `insert-after`：锚点必须恰好出现一次。
- `upsert-managed-block`：只维护带唯一标记的受控片段；可携带
  `expectedPrevious` 检查上一个管理版本。
- `delete-managed-block`：只能删除带同一受控标记的片段。

如果玩家修改了目标片段，使前置条件不再成立，运行层会记录冲突并保留玩家版本。
玩家在目标片段以外新增的角色设定、开场白和世界书内容不会被扫描或删除。

## 世界书条目安全

普通条目使用唯一名称和可选 UID 定位。新增条目会写入
`extra.caelianManagedId`；删除命令只能删除具有相同管理标记的唯一条目，
不能按模糊名称批量删除玩家条目。

玩家可以在设置面板关闭自动内容更新，也可以随时手动检查并重试发生冲突的命令。
