# Alpha 最终生产配置战斗复核（2026-09-07）

采用实际生产 API，外部攻击/生命倍率均为1。启动断言：Lv100利维坦ATK=1386、HP=103144、普通咬合倍率=240%；没有重复叠加等级压力。

## 最终配置与最小修正

x=clamp((等级−1)/99,0,1)：普通额外攻击×(1+0.5x)，精英/Boss×(1+2x)。HP不增加；每级10属性点与原AP/抽牌预算保留。利维坦咬合由45+285%ATK改为45+240%ATK，保留大招、反制、部件与助手合计25%普攻预算。

修正依据：固定16场利维坦对照中，285%为8胜4死4超时；240%为10胜2死4超时；220%没有增加胜场。助手预算25%降至15%没有改变12场慢职业的胜/死/超时，因此未削助手。Boss HP1.15/1.3只延长慢构筑战斗，未解决问题，因此未加HP。

## 可复跑

独立脚本scripts/simulate-battle-rework.mjs不依赖research目录的src链接。需要生产工程自身的Node环境；只读取工程，结果写到指定输出目录。

```powershell
node scripts/simulate-battle-rework.mjs . ./dist/battle-simulation
```

输出final-production-cases.jsonl包含264场原始结果，final-production-summary.json包含配置、源文件SHA256、输入断言、按职业/构筑/等级分类与全部失败场次。脚本默认执行200随机+64固定，未给玩家增加调试生命/AP、未固定暴击、未每轮重建手牌；赢必须所有存活敌人归零。

相关测试：Boss机制13/13、普通怪97种868技能路径13/13、正式仓储新契约7/7均已通过。仓储吸血fixture用500/1000HP，不设伪冷却键；同时满足吸血条件与避开低血守护优先级。

商人按用户最终要求保留原初始牌组，不补发通用攻击卡。本报告记录发布前已经完成的模拟，之后不增加测试批次。
