# 创意工坊：DOT 扩散与引爆

适用版本：Alpha 84、Beta 1.23 起。

## 扩散原目标已有的 DOT 种类

1. 编辑卡牌，添加「组合规则」。
2. 在「从示例／我的模板开始」中选择「DOT 扩散：排除原目标」。
3. 「DOT 筛选」选「全部 DOT」，或选「指定种类」并勾选中毒、灼烧等。指定种类后一个也不勾，不会处理任何 DOT。
4. 「检测来源」保持「本次选中目标」。
5. 「对象」选择「筛选目标 → 敌方存活单位 → 全部符合者」，勾选「除选中目标外」。模板已这样设置。
6. 填写每跳攻击倍率、持续回合、每种 DOT 施加层数、可叠加上限和基础命中率。

例如：攻击倍率 0.35、持续 3 回合、每种 1 层、叠加上限 5。选中 A，A 有中毒和灼烧，其他存活敌人为 B、C：B、C 分别尝试获得 1 层中毒和 1 层灼烧；A 不变。如果 A 只有中毒，就只施加中毒。

倍率 0.35 表示扩散者施加时攻击力的 35%，随扩散卡星级计算；不是固定 0.35 点伤害。不复制原层的伤害、回合或来源。每种施加层数是本次新增数量，叠加上限是最多保留数量，各层分别判定命中与抵抗。同类满层时遵守现有工坊 DOT 的伤害和剩余回合保留规则。

## 按原伤害引爆

1. 在另一张卡的组合规则中选择模板「DOT 引爆：原伤害结算并清除」。
2. 「DOT 筛选」选择全部或指定种类。
3. 「对象」默认当前目标；群体引爆可改成「筛选目标」。需要时同样勾选「除选中目标外」。
4. 「结算方式」选「每层结算一跳」或「每层结算全部剩余次数」。
5. 「原伤害倍率」填 1，表示 100%；1.5 表示 150%。它不是固定伤害。
6. 勾选「清除参与引爆的 DOT」，会消耗本次符合筛选的所有层；不勾选则保留原回合和层数。

例如 3 层中毒各 30 基础伤害、2 层灼烧各 50：一跳模式的基础伤害合计 190。每层仍按原施加者等级和目标当前防御、护盾独立结算；不会重新读取引爆者攻击力，不重复乘引爆卡星级，不暴击、不闪避。实际扣血可能低于 190。

全部剩余次数模式使用每层自己的剩余次数。整场 DOT 没有有限的总剩余伤害，在这个模式下只结算一跳。极高次数仍受既有单次积木执行保护约束，超出时会报错。

## 自己写引爆公式后清空 DOT

先用「造成伤害」配置层数或种类数对应的伤害，再添加「清除 DOT」。设置相同目标，并选择全部或指定 DOT 种类。

「清除 DOT」会删除匹配的所有独立层，包括不可净化的 DOT。其他 Buff、Debuff 和自定义父状态保留；父状态附带的 DOT 清除后，不会由这一份父状态自动补回。它与「净化」不同，净化还可能删除其他减益。

## 选中目标与当前目标

「本次选中目标」固定指本次规则事件开始时的目标。「当前目标」会在「逐个目标执行」和目标筛选内部变成正在处理的单位。排除选中目标始终使用前者，延迟执行也保留这个身份。
